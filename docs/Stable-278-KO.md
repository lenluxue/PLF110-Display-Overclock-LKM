## 正式参数

| 参数 | 值 |
| --- | --- |
| 模式顺序 / KO 索引 | 60 / 90 / 120 / 30 / 144Hz，索引 0 / 1 / 2 / 3 / 4 |
| 144Hz 像素时钟 | 464486kHz |
| H：有效 / 同步起点 / 同步终点 / 总计 | 1080 / 1209 / 1213 / 1229 |
| V：有效 / 同步起点 / 同步终点 / 总计 | 2392 / 2569 / 2571 / 2625 |
| 144Hz 动态链路 | 1399Mbps |
| 原厂链路 / PLL | 1162Mbps / 581 |
| 动态 VSA / VBP / VFP | 2 / 54 / 177 |
| 动态 HSA / HBP / HFP | 4 / 16 / 129 |
| `dyn_fps.vact_timing_fps` | 120 |

时序计算为 `464486000 / (1229 * 2625) = 143.976442326Hz`，
`mode_refresh()` 将其四舍五入为 144。这个计算值与面板实际扫描率需要分别验证；
链路数据率、DSC 和厂商动态时序实现也参与实际输出。

KO 索引与 ColorOS 刷新率策略 ID 属于不同接口，不能将两者的所有数字混用。

## 捕获、校验与注入

模块加载后先安装 panel / porch 探针，捕获经过面板名称校验的 DSI 实例。
`enable=1` 时核对原厂四个模式、完整 H/V 时序、基础链路及 callback KCFI 类型。
成功后复制原厂 120Hz 模式和完整 ext 参数，在副本中写入上述自定义时序。

`plf110_panel_get_modes()` 在原厂枚举之后追加自定义模式，
`plf110_connector_fill_modes()` 重建连接器列表，并维持四个原厂模式及新增模式
的固定顺序。connector / CRTC 的可用模式、映射及属性缓存随后重建，发送 hotplug。
已安装回调期间模块持有自身引用。

原厂未知模式、重复模式或 ext 参数不符会触发校验失败；这一实现仍依赖厂商
结构体布局、符号 CRC 和 KCFI ABI，不能只凭内核小版本号推断兼容性。

## 切档与 120Hz 面板配置

`plf110_ext_param_set/get()` 遇到自定义档位时，先按原厂 120Hz 的索引调用
原回调，再选择自定义 ext 参数。顶层 PLL、DSC、ESD、指纹及亮度数据继续沿用
原厂配置，`dyn_fps.vact_timing_fps` 保持 120。

`plf110_mode_switch_update_for_vdo()` 在进入自定义档时调用 `switch_link(true)`，
通过 `MIPI_HOPPING` 请求 1399Mbps；退出时调用 `switch_link(false)` 恢复 1162Mbps。
返回后检查 hopping 状态及主 / 从 DSI 数据率。

正式 KO 的动态 ext 初始化和切档检查各包含一个 1399Mbps 立即数。
修改链路必须覆盖这两处。修改像素时钟则需要同步模式创建、枚举、扫描、
ext 参数匹配等所有内联校验，不能只修改模式赋值处。

面板枚举钩子让厂商对自定义 144Hz 使用 `FHD_SDC120` 命令配置；
OFP 钩子仅在指纹 HBM 的对应调用上下文将刷新率返回值 144 改为 120。
DRM 中的自定义时序保留，其他应用的刷新率读取不受这一局部映射影响。

## 配套模块的生效流程

KO 负责内核模式和切档。Stable-278 的 `service.sh` 在系统启动完成、
开机动画停止后，确认 SurfaceFlinger 与 `vendor.hwcomposer-3-2` 已运行，
以本次 boot ID 为标记重启一次 vendor HWC，使用户空间重新读取档位。

ColorOS 配套逻辑从当前系统配置生成应用策略，维持全局 144Hz 上限，并对
配置或手动选择为 144Hz 的前台应用启用应用请求优先级，帮助其在通知栏、
小窗等 120Hz 请求结束后恢复。普通应用、短视频和排除的游戏按包内策略处理。
这些属于用户空间逻辑，不能靠修改 KO 的像素时钟代替。

Stable-278 已移除 MTK Perf 配置。当前仓库保留 LKM 源码及说明，完整安装包
由发行版提供。

## 源码与发行产物的关系

仓库提供可审阅的参考实现。上述正式资产沿用已验证 KO，定点调整链路常量；
使用不同生成头、工具链配置或参考实现中的兼容回退代码重编译，不能保证与
发行 KO 字节一致。这里的静态复核也不替代设备上的亮度、指纹、切档与刷新率测试。
